Security & Anti-Cheat Compliance

Engineered for 100% Account Safety

We understand player skepticism regarding third-party tools and Warden anti-cheat bans. Here is the exact technical proof why Akimbo is completely safe, transparent, and fully compliant with Blizzard's Terms of Service.

Zero Process Injection

Akimbo never calls WriteProcessMemory, injects DLLs, or hooks WoW's executable. Blizzard's Warden scans for foreign code injected into WoW's memory; Akimbo leaves game memory 100% untouched.

Zero Memory Reading

Akimbo has no access to your player coordinates, inventory, gold, health, or combat logs. The companion runs in standard user space with zero ReadProcessMemory calls.

Zero Input Automation

Akimbo contains zero input simulation (no SendInput or synthetic key events). It is purely a display layout tool. One physical click or keypress always equals exactly one game action.

Plain-Text Auditable Code

No compiled mystery .exe binaries or packed code. The companion is open-source PowerShell (Akimbo-Companion.ps1) that you can open and inspect line-by-line in Notepad before running.

Why is an external companion tool needed at all?

Blizzard's in-game Lua engine runs inside a restricted security sandbox with zero access to the Windows operating system. An in-game addon cannot resize or reposition the actual OS window across physical monitors.

Simultaneously, CurseForge & Overwolf enforce strict policies that forbid packaging executable scripts (.bat, .ps1, .exe) inside addon zip archives. Akimbo cleanly separates these concerns: the CurseForge Addon manages your in-game frames and 3D camera viewport, while the Open-Source Companion tells Windows to stretch the borderless window across both displays.

Prefer not to use our companion script? You don't have to! Akimbo is 100% compatible with veteran window management software like Borderless Gaming (used by over 5 million players on Steam) or DisplayFusion.

Common Questions

Frequently Asked Questions

Everything you need to know about setup, safety, and compatibility.

Will Blizzard's Warden anti-cheat flag or ban me?

No. Blizzard's Warden monitors for unauthorized process tampering (such as WriteProcessMemory or DLL injection) and input automation bots. Akimbo uses standard Windows desktop manager APIs (user32.dll SetWindowPos) strictly to resize and position the window frame, exactly like OBS, Discord, and Borderless Gaming. It touches zero game RAM and automates zero inputs.

Why can't this be packaged 100% inside CurseForge?

CurseForge / Overwolf has a strict, positive security rule that bans executable scripts (.bat, .ps1, .exe) inside addon packages. Furthermore, Blizzard's Lua sandbox prevents in-game code from manipulating the Windows desktop. Therefore, the in-game addon (CurseForge) manages camera FOV & UI layout, while the companion script (GitHub) spans the desktop window.

Can I inspect the companion code before running it?

Yes, 100%! We intentionally built the companion as an uncompiled, plain-text PowerShell script (Akimbo-Companion.ps1). You can right-click it and open it in Windows Notepad, VS Code, or view it directly on GitHub. There are no obfuscated binaries, hidden compilers, or mystery code.

Does Akimbo connect to the internet or collect telemetry?

No. The Akimbo companion contains zero network sockets, zero HTTP requests, and zero analytics or phone-home beacons. It is 100% offline and functions entirely locally on your machine.

Can I use Borderless Gaming or DisplayFusion instead?

Absolutely! The in-game Akimbo addon only cares that the game window spans both monitors. If you already use Borderless Gaming (on Steam), DisplayFusion, or AMD Eyefinity / NVIDIA Surround, you do not need our companion at all. Simply span the window and run /akimbo wizard in-game.

Why does the companion check if the addon is installed?

To prevent awkward window states! If you ever disable or uninstall the Akimbo addon, the companion detects that the addon TOC file is missing and safely refuses to span WoW. This guarantees your game window only spans when your UI and camera are ready for it.

Does it work with different monitor sizes & refresh rates?

Yes. Akimbo was specifically designed for mixed setups, such as a vertical portrait monitor (e.g. 1440x2560) paired with a curved 16:9 or ultrawide 21:9 gaming monitor, as well as matching side-by-side displays. Monitors with different refresh rates (e.g., 144Hz + 60Hz) work smoothly in Windows borderless mode.

What happens if I pause or exit the companion?

The companion has a "Pause Monitoring" toggle and an "Exit" button in both the GUI and system tray. When closed, it leaves zero persistent services, drivers, or background tasks running.
